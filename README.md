# 梦（Meng）输入法

一个基于 fcitx5 内核的 Android 中文输入法，包名 `com.meng.ime`。

---

## 功能

- **智能联想** - 上屏后自动预测下一词（基于词频统计）
- **拼音纠错** - 打错拼音也尽量猜对，支持习惯码、模糊音、邻键误触、长码替换
- **方案商店** - 直接在手机上安装/更新/卸载 Rime 输入方案，自带万象拼音，不用重装 App
- **主题商店** - 下载键盘皮肤，也能自定义配色和布局
- **剪贴板管理** - 历史记录、搜索、分组、编辑
- **剪贴板同步** - 基于房间的加密同步，多设备共享剪贴板
- **备份/恢复** - 导出设置、词表、剪贴板，换机可迁移

## 智能联想与纠错

联想和纠错直接在**输入法内核**里实现，结果显示在候选框内，不做独立界面。内核只读取程序管理的词表，不自行生成词表。

## 技术构成

- 主程序：Kotlin，`app/`
- 联想/纠错内核源码：C++，`plugin/rime/`
- 预编译 `.so` 库：自行修改维护，随仓库存储
- 词表数据：`app/src/main/assets/smart-input/`
